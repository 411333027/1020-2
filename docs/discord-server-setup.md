# Discord Server 設定步驟

這份文件帶你做三件事：

1. 建立一個你自己的 Discord Server（伺服器）
2. 建立一個給 agent 用的頻道，並拿到它的 `CHANNEL_ID`
3. 產生邀請連結，讓同組同學加入你的 Server

**你的電腦是 Windows。** 下面的步驟用 Windows 的 Discord 桌面程式或網頁版（`https://discord.com/app`）都可以，畫面一樣。

> Discord 偶爾會改版，按鈕的位置或文字可能和這裡有一點出入。文件裡中文名稱後面會附上英文，萬一你的 Discord 是英文介面，可以對照。

**名詞先講一下**

- **Server（伺服器）**：Discord 裡一個「社群空間」，像一棟大樓。你是主人，可以決定誰能進來。
- **頻道（Channel）**：Server 裡的一個「房間」。文字頻道就是聊天室。
- **CHANNEL_ID**：每個頻道的編號，是一串很長的數字。agent 靠這個編號知道「只聽哪一個房間」。

---

## 一、建立你自己的 Server

1. 打開 Discord，登入你的帳號。
2. 看畫面**最左邊**那一排圓形圖示（這是你加入的 Server 清單）。拉到最下面，找到一個 **「＋」** 圖示，按它。
   - 滑鼠移上去會顯示「新增伺服器」（Add a Server）。
3. 跳出視窗後，選 **「自己建立」**（Create My Own）。
4. 下一個畫面問「這個伺服器是給誰用的？」，選 **「與朋友一起」**（For me and my friends）。
5. 在「伺服器名稱」欄位輸入名字，例如 `食物記錄`。
   - 圖示可以不用上傳。
6. 按 **「建立」**（Create）。

完成後，你會被帶進新的 Server，左邊那排會多一個你剛建的圖示。

---

## 二、建立 agent 用的頻道，並拿到 CHANNEL_ID

### 2-1 建立頻道

1. 在你剛建的 Server 裡，看**左邊第二欄**（頻道清單）。你會看到「文字頻道」（Text Channels）這個分類，下面預設有一個 `一般`（general）。
2. 把滑鼠移到「文字頻道」這四個字上，右邊會出現一個 **「＋」**，按它。
   - 也可以在空白處按右鍵，選「建立頻道」。
3. 跳出視窗後：
   - 頻道類型選 **「文字」**（Text）。
   - 頻道名稱輸入 `食物記錄`（英文用 `food-log` 也行）。
   - 「私人頻道」（Private Channel）**先不要打開**。如果打開，同學進來也看不到，之後測試會多一道麻煩。
4. 按 **「建立頻道」**。

之後 agent 只會聽這一個頻道，其他頻道（例如 `一般`）傳什麼照片它都不會理。

### 2-2 打開「開發者模式」（為了複製頻道編號）

Discord 預設把「複製編號」藏起來，要先打開開發者模式，**只需要做一次**。

1. 看畫面**左下角**，你的頭像旁邊有一個 **齒輪圖示**（使用者設定，User Settings），按它。
2. 在左邊清單往下找到 **「進階」**（Advanced）。
   - 它在「App 設定」（App Settings）區塊底下。
3. 找到 **「開發者模式」**（Developer Mode），把右邊的開關**打開**（變成綠色）。
4. 按右上角的 **「X」**（或鍵盤 `Esc`）離開設定。

### 2-3 複製 CHANNEL_ID

1. 在左邊的頻道清單，對 `食物記錄` 這個頻道按**滑鼠右鍵**。
2. 在選單最下面按 **「複製頻道 ID」**（Copy Channel ID）。
   - 看不到這個選項，代表開發者模式沒打開，回到 2-2。
3. 打開記事本（Notepad），按 `Ctrl + V` 貼上，你會看到一串 18～19 位的數字，例如 `123456789012345678`。
4. 先留著，之後要寫進 `.env` 設定檔：

   ```
   CHANNEL_ID=123456789012345678
   ```

   （上面是範例，要換成你自己的數字。）

> `CHANNEL_ID` 只是房間編號，不是密碼，貼給別人沒關係。真正不能外流的是 bot token，見 `docs/discord-bot-setup.md`。

## 三、產生邀請連結，讓同組同學加入

### 3-1 建立連結

1. 對左邊第二欄**最上面的 Server 名稱**（`食物記錄`）按一下。
   - 會出現下拉選單。
2. 按 **「邀請朋友」**（Invite People）。
3. 跳出視窗，最下面有一條邀請連結，格式像 `https://discord.gg/xxxxxxx`。
4. 先**不要急著複製**，按視窗底下的 **「編輯邀請連結」**（Edit invite link，或齒輪圖示）設定限制，往下看。

### 3-2 設定連結的限制（建議做）

任何拿到連結的人都能進你的 Server，而且進來後**就能在頻道傳照片，每一張都會用掉你自己的 Claude 額度**。所以建議設限制：

1. **「連結到期時間」**（Expire After）：選 **「7 天」**，測試完就失效。
2. **「使用次數上限」**（Max number of uses）：選你同組的人數，例如 `5`。
3. 其他選項（例如「給予臨時成員資格」）**保持關閉**。
4. 按 **「產生新連結」**（Generate a New Link）。

### 3-3 傳給同學

1. 按連結右邊的 **「複製」**（Copy）。
2. 用你平常聯絡同學的方式（LINE、群組等）貼給他們。
3. 同學點開連結 → 登入他們的 Discord → 按 **「接受邀請」**（Accept Invite）就會進來。

### 3-4 確認同學真的進來了

1. 看畫面**最右邊**的成員清單（沒看到的話，按頻道上方標題列右邊的「成員」圖示）。
2. 同學進來後，他們的名字會出現在這裡。

### 3-5 以後要收回連結

在「邀請朋友」視窗，或到 Server 名稱旁的下拉選單 →「伺服器設定」（Server Settings）→「邀請」（Invites），可以看到所有連結，按 **「X」** 就能立刻讓它失效。
